## Design Specificity Verdict

**LLM assessment (Assessment A):** Landing, Brief, and Results feel genuinely authored for a naming tool — the mono-uppercase eyebrows, the giant Inter-black headline, the numbered name list with live availability dots, and the "Simple / Memorable / Meaningful" footer triads build a consistent, specific voice. Compare breaks this. Once inside it, the UI reverts to generic B2B-comparison furniture: a 6-item icon sidebar with off-the-shelf Lucide icons, tables with a "winner" color unrelated to the rest of the palette, and a "Beta" AI badge that could sit on any SaaS product. Swap the row labels ("Brand match," "Pronunciation") for "Price," "Shipping" and it's a template. The new violet accent reads as bolted-on rather than integrated — it's used in exactly two places while the actual "winning" logic elsewhere still runs on the old neon green, so the app now carries three unreconciled foreground accents (white, green, violet).

**Deterministic scan (Assessment B):** The static CLI scan (`impeccable detect`) came back clean, exit 0, zero findings — but the browser-runtime detector found 17 findings across the 4 pages it injected on (Landing: 0, Brief step 4: 1, Compare: 14, Shortlist: 2), all concentrated in computed CSS (resolved Tailwind utilities, actual rendered font sizes, real contrast ratios) that the static scan can't see. Compare alone accounts for 14 of the 17 runtime findings, including 7 ai-color-palette flags (violet/cyan neon-on-dark) and a legitimate WCAG failure (#7c3aed on #130924, 3.4:1 against a 4.5:1 requirement). The two assessments independently converge on the same screen and the same root cause from completely different methods.

**Visual overlays:** No user-visible browser overlay was left running — Assessment B started the live server, injected the detector, captured console + impeccableScan() output, and stopped the server afterward.

## Overall Impression

The core funnel (Landing → Brief → Results) is well-crafted and specific — it doesn't feel like a template. Compare, the newest and most complex screen, is where the product's design voice collapses into generic dashboard patterns, and it's also where every category of real defect concentrated: a P0 text-wrapping bug that breaks the actual generated name, a dead-end nav tab, undefined color semantics, and 82% of the runtime-detected issues.

## What's Working

1. ResultsNameList's scroll-snap + IntersectionObserver sync — selecting a card scrolls it to center, scrolling updates the detail panel, with a guard ref to prevent feedback loops.
2. The brief's real-input-gated Continue buttons + Enter-to-submit — low friction, keyboard-first, no jarring empty-submit errors.
3. The footer triad pattern and per-step footer copy — small, consistent, on-voice copy reinforcing the product's philosophy at the edges of every screen.

## Priority Issues

**[P0] Domain name wraps mid-word in Compare cards.** "BRANDFORGE.COM" breaks across lines as "BRANDFORGE .C" / "OM" — confirmed independently by both assessments at 1440px. Fix: whitespace-nowrap on the TLD span, or force the suffix to its own line. Suggested command: /impeccable polish

**[P0] Compare's "Recommendation" sidebar tab is a dead end, and the active-tab indicator desyncs.** Clicking it shows only "See the AI Recommendation panel at the top of this page." The "Overview" pill stayed visually highlighted after switching tabs. Fix: drop "Recommendation" from the sidebar (5 real tabs); fix the active-state binding regardless. Suggested command: /impeccable layout

**[P1] Three unreconciled accent colors with no stated rule.** Neon green marks "available/winning" in Results and Compare's tables/checklists; violet marks the AI panel and active tab. Inside the violet-bordered AI panel, the checklist checkmarks are still neon green. The detector's 7 ai-color-palette flags on Compare are the measurable symptom. Fix: pick one accent for "positive/winning" semantics and apply it everywhere. Suggested command: /impeccable colorize

**[P1] Redundant copy stacked in the Compare header.** "Comparing 3 names." appears as page-intro subtext, then "Comparing 3 names" reappears as a section label ~80-150px below it. Fix: delete one instance; use the second slot for something new. Suggested command: /impeccable distill

**[P2] Muted text fails WCAG AA contrast at the sizes it's used.** #888888 on #000000 computes to ~3.9:1, below the 4.5:1 AA minimum, used for nearly all body/caption copy site-wide. Detector confirms adjacent issues: 8-9px text below the 11px floor, and one hard AA failure at 3.4:1. Fix: raise muted text to roughly #a3a3a3-#a8a8a8, bring sub-11px labels up to at least 11px. Suggested command: /impeccable audit

## Persona Red Flags

**Jordan (First-Timer):** Arriving at Compare with 0 items offers only "Start your brief" — no way to pull in names already in Shortlist. The dead-end "Recommendation" tab is exactly the kind of moment that makes a first-timer think they broke something.

**Casey (Mobile):** Mobile landing page recent-search names truncate mid-word ("BRANDF…", "SECUREMI…"). Below 1024px, Compare's 6-tab sidebar becomes a horizontally-scrolling pill row.

**Sam (Accessibility):** Contrast failures are the color used for nearly every secondary caption app-wide. No onKeyDown arrow-key handling found on the Results name list itself.

## Minor Observations

- Nav badge aria-label reads "3 compare names" (grammatically off) — should be "3 names in Compare."
- The TLD "+ More" chip silently discards previously-selected specific TLDs by setting the preference to "any", with no confirmation.
- CompareTable's "Pronunciation" row never highlights a winner (missing ranks array, unlike every other row).
- The "+Compare" button disables at the item cap with only reduced opacity — no tooltip explaining why.
- A floating circular "N" element appeared to overlap footer text in Assessment B's screenshots across every page — almost certainly the Claude desktop app's own browser-pane chrome, not part of NameGenius. Flagging so it isn't mistaken for a real defect.

## Questions to Consider

- What if Compare had no tabs at all — the AI Recommendation panel is the comparison, with the rest collapsed into expandable sections per card?
- What if violet became the single "AI thinks this is the answer" signal everywhere, so the user learns one meaning once?
- What if "Recent Searches" wasn't a 4th top-level nav item at all, but folded into the Brief's first step as one-tap "start from here" cards?
